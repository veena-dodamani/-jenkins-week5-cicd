# Week 5 Jenkins CI/CD Demo

A small Java application used for the Week 5 Jenkins, CI/CD and GitHub Integration assignment.

## Files
- `src/Hello.java` - sample Java application
- `build.bat` - compiles the application
- `test.bat` - runs a simple validation test
- `Jenkinsfile` - Declarative Jenkins pipeline with Checkout, Build and Test stages

## Local test
Run:
```bat
build.bat
test.bat
```
